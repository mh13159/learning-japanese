## What this app does now

Visit http://localhost:3000 (dev server is still running as bash task `b0hhkpn70`).

### Confirmed working
- **Japanese in (kanji+kana):** Kuroshiro+Kuromoji produces accurate kana + Hepburn romaji.
- **Romaji in:** wanakana → kana, with a rule-based fix that restores the particle exceptions (`wa→は`, `o→を`, `e→へ`). `konnichiwa` correctly produces `こんにちは`.
- **English in (single words / short queries):** Jisho.org public JMdict API returns curated answers. `good` → 良い, `umbrella` → 傘, `fish` → 魚, `house` → 家, `cat` → 猫, `tomorrow` → 明日, `translator` → 訳者, `beautiful` → 美しい.
- **English in (sentences):** LibreTranslate self-hosted in WSL Docker handles open-vocabulary translation. Quality varies — Argos's small EN-JA model is reliable on vocabulary, rough on natural sentence structure. UI now lowers `meta.confidence` to 0.6 and surfaces an advisory note when LibreTranslate is the source.
- **Async detection tiebreaker:** ambiguous ASCII inputs (e.g. `house`, `home`, `neko`, `hon`, `kanojo`) are resolved via a single Jisho lookup that classifies based on whether the literal string appears as an English gloss or as a Japanese reading on a common+JLPT-tagged entry.
- **TTS:** Play button uses `window.speechSynthesis` with `lang="ja-JP"`.
- **Speech recognition (mic):** Web Speech API `SpeechRecognition` with `lang="ja-JP"`. Chrome/Edge only; Firefox/Safari users see an unsupported message.

### Honest limitations (documented in README)
1. **LibreTranslate sentence quality.** Argos's distilled model is ~100 MB and not state-of-the-art. README §2 lists three FOSS upgrade paths (NLLB-200, OPUS-MT, or a custom FastAPI wrapper) that are drop-in compatible via `LIBRETRANSLATE_URL`. Each path is one Docker command away.
2. **Romaji → kanji disambiguation.** Romaji input produces kana-only output (`konnichiwa` → `こんにちは`, not `今日は`). Open problem in any FOSS pipeline without an LLM; the UI flags this explicitly in the romaji branch.
3. **Pronouns / context-dependent vocabulary.** `me` is genuinely ambiguous in Japanese (私 / 僕 / 俺 / 自分). Jisho doesn't disambiguate; LibreTranslate hallucinates. Future work could add a politeness-mode toggle.
4. **Some JMdict entries rank oddly.** `inu` may still surface 戌 instead of 犬 in certain code paths because both share the reading いぬ and the `lookupJapaneseWord` "exact match" iterator can pick either. The JLPT-tier sort applies to the picked-common branch; tightening it for the reading-match branch is a 5-line follow-up.

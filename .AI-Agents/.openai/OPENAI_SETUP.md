# OpenAI Setup Guide

## Overview

OpenAI API integration for GPT models.

## Getting Started

1. **Sign Up**: Visit https://platform.openai.com/
2. **Get API Key**: Create API key in account settings
3. **Environment Variables**:
   ```
   OPENAI_API_KEY=your_api_key
   ```
4. **Install SDK**:
   ```bash
   npm install openai
   ```

## Available Models

- GPT-4
- GPT-3.5-turbo
- Embeddings

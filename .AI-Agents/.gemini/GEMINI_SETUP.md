# Google Gemini Setup Guide

## Overview

Google Gemini API for multimodal AI tasks.

## Getting Started

1. **Sign Up**: Visit https://makersuite.google.com/
2. **Get API Key**: Create API key in Google AI Studio
3. **Environment Variables**:
   ```
   GOOGLE_GEMINI_API_KEY=your_api_key
   ```
4. **Install SDK**:
   ```bash
   npm install @google/generative-ai
   ```

## Available Models

- Gemini Pro
- Gemini Pro Vision

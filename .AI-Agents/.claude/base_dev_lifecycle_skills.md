# Base Dev Lifecycle Skills

Core development lifecycle competencies for automated workflows.

## Skills

- **Code Analysis** - Static code analysis and quality checks
- **Testing** - Unit, integration, and E2E testing automation
- **Linting & Formatting** - Code style enforcement
- **Build Automation** - Compilation and bundling
- **Deployment** - CI/CD pipeline orchestration
- **Monitoring & Logging** - Performance and error tracking
- **Documentation** - Auto-generation and maintenance
- **Refactoring** - Code optimization and modernization
